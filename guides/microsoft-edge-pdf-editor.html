Microsoft Edge's PDF editor: how to add text, draw and sign, and what it can't do (2026)

If you're on Windows, Edge is probably already your PDF reader. It can do more than most people realise: add text, draw, highlight, add notes and fill forms, then save a copy. Here's how to use each tool, and where Edge runs out.

Updated October 2026 · 6 min read

What changed: Edge's PDF reader now uses Adobe's engine

Edge's PDF reader has been rebuilt on Adobe Acrobat's PDF rendering engine. Here's how that happened, according to Microsoft:

  • May 2025: Microsoft announced the new viewer "powered by Adobe engine" for testing in Edge Beta, starting with version 136, and planned to make it the default in the Stable channel from mid to late October 2025 (Microsoft 365 message MC1072406, as mirrored by mc.merill.net).
  • Edge 156: Microsoft says the built-in reader "has transitioned to the newer version". The policy organizations used to keep the old viewer is deprecated and is planned to stop working from Edge 162 (Microsoft Learn, NewPDFReaderEnabled policy, updated October 2026).

Microsoft describes the change as better rendering, performance, security and accessibility, with "no loss of functionality". Neither notice lists new editing tools. You don't get merging or redaction from it. The new viewer also didn't make XFA forms work for everyone: viewing XFA PDFs through IE mode is listed as a feature for organizations only (MC1072406).

How to use Edge's PDF tools

Open the PDF in Edge: double-click it if Edge is your default PDF app, or right-click the file and choose Open with → Microsoft Edge. The tools sit in the PDF toolbar at the top of the page. The steps below follow Microsoft's Edge PDF documentation and Edge's PDF reader page (October 2026). Microsoft notes that features can vary by device, market and browser version.

Fill in form fields

If the PDF has real form fields, click a field and type. Microsoft calls this "basic form filling" and says forms that rely on JavaScript aren't supported. If clicking a blank line does nothing, the PDF is flat. Use Add text instead, or see how to fill a non-fillable PDF.

Add text anywhere

  1. Select Add text in the PDF toolbar.
  2. Click where you want the text and start typing.
  3. Select the text box to move it or change the font.

Draw (ink) and highlight

  1. Select the ink (Draw) tool in the PDF toolbar. You can change the ink colour and stroke width.
  2. Draw with your mouse, trackpad, pen or touchscreen.
  3. To highlight, select some text, right-click it, choose Highlight and pick a colour.

Add a note

Select some text, right-click, and choose Add comment. Type your note and click the check mark. The text gets highlighted and a comment icon appears; hover over it to read the note.

Sign

Edge has no Sign button. Microsoft says inking is useful to "sign, or fill out PDF forms", so use Draw: zoom in on the signature line so you have room, then draw your signature. A pen or touchscreen makes this much easier than a trackpad.

Save your changes

Use Save or Save as in the PDF toolbar. Microsoft says you "can save a copy of the PDF with your highlights and markings". Save as is the safer choice, so you keep the original.

Check the saved file. Open the saved copy before you send it and make sure your text and signature are there.

Edge can also read a PDF aloud, show its table of contents, and view and validate certificate-based digital signatures that are already in a file (Microsoft). Validating someone else's digital signature is not the same as creating one: Edge doesn't create certificate-based signatures.

The ones that matter most

Redaction. If you draw or highlight over an account number in Edge, the number is still in the file under your mark. Anyone can copy it out. Our guide on how to redact a PDF properly explains the difference and has a 30-second test.

Signatures. You redraw your signature every time, and a drawn signature is a visual mark on the page, not a certified digital signature. That's fine for most leases, permission slips and HR forms. If someone asks for a certificate-based signature, you need a different tool.

Pages. Edge can't merge two PDFs, drop a page or change the page order. Windows doesn't include a tool for this either.

XFA forms. Some government and corporate forms are XFA forms. Microsoft's documentation says XFA "isn't supported in Microsoft Edge" (Microsoft), apart from the IE mode option for organizations. If you see a "Please wait..." message, see our XFA guide.

When Edge is enough

  • The PDF has form fields and you just need to type into them.
  • You need a few words on a flat form.
  • You can sign with a drawn signature, and only occasionally.

If that's you, you're done. You don't need anything else.

When you need something else

  • XFA forms: save the file and open it in the free desktop Adobe Acrobat Reader for Windows or Mac.
  • Merging lots of files: PDFsam Basic is a free, open-source desktop app for Windows, macOS and Linux that merges, splits, rotates and extracts pages offline. More options are in how to merge PDFs without uploading them.
  • Saved signatures, redaction, white-out and page tools in the browser: see below. Be careful with online PDF editors: many upload your file to their servers.
