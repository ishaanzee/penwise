How to merge PDFs without uploading them

Most "merge PDF" results are websites that ask you to upload your files first. You don't have to. Here's how to combine PDFs on your own device on Windows, Mac and Chromebook, all for free.

Updated October 2026 · 6 min read

The short answer

  • Mac: Preview can do it. It's already installed.
  • Windows 11: there's no built-in merge tool. Use a free desktop app (PDFsam Basic) or a browser tool that works locally.
  • Chromebook: the built-in Gallery app can reorder pages but doesn't merge files. Use a Chrome extension or a local web app.
  • Any computer with a browser: a tool that opens the PDFs inside the browser tab, rather than on a server, works everywhere.

On a Mac: Preview

Preview combines PDFs by dragging pages from one document into another. From Apple's guide:

  1. Open the PDFs you want to combine in Preview.
  2. In each one, choose View → Thumbnails to show the page sidebar.
  3. Drag the thumbnails you want from one PDF's sidebar into the other's. Drop them at the end or between pages. Command-click to pick pages that aren't next to each other.
  4. To add a whole PDF, drag its icon from Finder into the sidebar.

To tidy up, drag thumbnails to reorder them, select a page and press Delete to remove it (Apple), or use the Rotate Left tool on a page that's sideways (Apple).

Make a copy first. Apple notes that changes in Preview "are saved automatically." Choose File → Duplicate before you start if you want to keep the original files as they were.

On Windows 11

Windows 11 doesn't include a tool for combining PDFs, and Microsoft Edge's PDF viewer can't merge or reorder pages either; it only rotates the view (Microsoft's Edge PDF documentation).

What about Microsoft Print to PDF? It's a virtual printer: it turns whatever you print into a PDF, one print job at a time. It has no "add file" option. People on Microsoft's community forum describe multi-step workarounds built on it, but other replies in the same thread call it "a workaround, not a dedicated pdf merger" and say it gets cumbersome beyond two or three files. We wouldn't rely on it.

Two better options:

Option 1: PDFsam Basic (free desktop app)

PDFsam Basic is "a free and open source app that splits and merges PDF files on your own computer," released under the AGPL licence, for Windows, macOS and Linux. Its site says "everything runs locally so your files are never uploaded and no internet connection is needed." It's a good choice if you merge PDFs often, want to work fully offline, or need to combine dozens of files at once. You do need to install it.

Option 2: a browser tool that works locally

If you can't or don't want to install software (on a work laptop, say), use a browser-based tool that opens the files inside the tab instead of uploading them. See the Penwise section below, or check any tool with the network test in our guide to whether it's safe to upload PDFs online.

On a Chromebook

ChromeOS's Gallery app opens PDFs and, per Google's Chromebook help, can change the order of pages (drag them in the left column, or Ctrl + Up/Down) and rotate pages from the sidebar, and it mentions deleting pages. That help page doesn't describe combining separate PDF files, and we couldn't find any Google documentation saying Gallery can merge.

Chrome's own PDF viewer can't merge or reorder pages either; it only rotates the view (see Chrome's PDF help for what it does offer). So on a Chromebook, merging means a Chrome extension or a web app. Pick one that processes files locally, since many "merge PDF" extensions are just shortcuts to an upload website.

Is it safe to merge PDFs online?

Usually nothing bad happens. Reputable online mergers encrypt the upload and delete files after a set time. As of October 2026, Smallpdf says "files are deleted after one hour unless you save or share them for longer" (smallpdf.com), and Sejda says files are "automatically deleted after 2 hours" (sejda.com).

The trade-off is that, for that hour or two, a copy of your document sits on someone else's server, and you're trusting their policy and their security. That's fine for a menu or a flyer. It's a bigger ask for the things people most often need to merge: tax returns, bank statements, ID scans, medical records and signed contracts. Merging on your own device takes the question off the table. We compare five services' policies in Is it safe to upload a PDF to an online editor?

After merging, check the result. Scroll through every page in a second viewer to confirm nothing is missing, sideways or out of order. If the merged file has sensitive parts you need to hide before sending, see how to redact a PDF properly.

FAQ

Can I merge PDFs on Windows 11 without installing software?

Not with a built-in tool. Windows 11 and Edge have no merge feature, and Microsoft Print to PDF is a virtual printer, not a merger. Without installing anything you can use a browser-based tool that works locally, such as the Penwise web app. If you're happy to install a program, PDFsam Basic is free, open source and works offline.

How do I combine PDFs on a Mac for free?

Use Preview. Open the PDFs, choose View → Thumbnails in each, and drag thumbnails from one sidebar into the other. Choose File → Duplicate first if you want to keep the originals.

Can you merge PDFs on a Chromebook?

The Gallery app can reorder, rotate and delete pages, but Google's help page doesn't describe merging files. Use a Chrome extension or a web app that works locally, such as Penwise.

Is it safe to merge PDFs online?

Reputable tools encrypt uploads and delete files after a set time (one hour at Smallpdf, two at Sejda). It's still a copy on someone else's server for that time, so for sensitive documents, merge on your own device.
